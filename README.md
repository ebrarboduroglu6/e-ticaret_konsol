# E-Ticaret Sepet Uygulaması

Bu proje, Python ile hazırlanmış basit bir e-ticaret sepet uygulamasıdır. Kullanıcı ürünleri görüntüleyebilir, sepete ürün ekleyebilir, sepeti görüntüleyebilir, sepetten ürün çıkarabilir ve siparişi tamamlayabilir.

## Özellikler

- Ürün listesini görüntüleme
- Sepete ürün ekleme
- Stok kontrolü
- Sepeti görüntüleme
- Sepetten ürün çıkarma
- Siparişi onaylama veya iptal etme
- Uygulamadan çıkış yapma
